UDS Warehouse

Type in search box the item that you are looking for. The search triggers automatically when 3 or more characters are input

Syntax of the search:

  • Free text: Search in Name, Description, Damages, Checklist, Holder, Location, StorageGuidelines.
  • Terms: Space = OR, & = AND.
  • Exact Phrase: "search phrase" (Escapes : < > = &).
  • Prefixes:
    • id:101 - Search by ID.
    • type:Marketing - Search by type e.g. marketing.
    • category:Events - Search by category e.g. events.
    • holder:Name - Search by holder name/email. Using holder:me uses your email (if logged in).
    • location:Seattle - Search by location (Tacoma, Seattle).
    • name:Title - Search by item name.
    • owner:Name - Search by owner name/email. Using owner:me uses your email (if logged in).
    • stored:text - Search in StorageGuidelines.
    • description:text - Search in Description.
    • damages:text - Search in Damages.
    • checklist:text - Search in Checklist.
    • log:text - Search in Log.
    • donor:Name - Search by donor name/email. Using donor:me uses your email (if logged in).
  • Dates:
    • registered>YYYY-MM-DD registered after the date,
    • updated>YYYY-MM-DD updated after the date,
    • registered<YYYY-MM-DD registered before the date,
    • updated<YYYY-MM-DD updated before the date.
